# Regime-specific diagnostics

Some flow regimes have physics that no general metric captures. Near a wall the flow is
organised by the friction at the wall, a mixing layer between fluids of different density
can be stirred without being mixed, and in a reacting flow the questions that matter concern
the flame. A metric that is blind to these regime-specific quantities can rate a prediction
highly while the physics a user cares about is wrong, so each regime needs its own
diagnostics. The ideas in this theme apply only to data from their regime, and each page says
which quantities define it.

## Ideas in this theme

- [Wall-bounded flow diagnostics](wall_bounded_flows.md): friction velocity, wall units, the
  logarithmic law of the wall with a flow-dependent constant, skin friction and separation.
- [Variable-density mixing](variable_density_mixing.md): mixing width and its growth laws, the
  molecular mixing fraction, variable-density second moments, persistent anisotropy and
  mixing geometry.
- [Reacting-flow and scalar-mixing diagnostics](reacting_flows.md): mixture fraction and
  conditional statistics, scalar dissipation, flame surface density, the flame index and
  thermochemical bounds.
